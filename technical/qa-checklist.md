# QA Checklist — AI Revenue Agent

Launch testing checklist for the AI Revenue Agent.

---

## Lead Flow
- [ ] New leads ingest correctly.
- [ ] Enrichment data populates on each lead.
- [ ] Qualification scores apply correctly.
- [ ] Qualified leads move into outreach.

## Outreach
- [ ] Email templates render correctly.
- [ ] LinkedIn/SMS sequences trigger properly.
- [ ] Follow-up timing is correct.
- [ ] Paused when meetings are booked.

## Booking
- [ ] Calendar availability displays correctly.
- [ ] Bookings are confirmed.
- [ ] Meeting invites and reminders are sent.

## CRM Sync
- [ ] Lead fields map correctly.
- [ ] Status updates sync.
- [ ] Opportunities update with booked meetings.

## Reporting
- [ ] Key metrics surface correctly.
- [ ] Alerts fire on failures.
- [ ] Dashboard reflects live data.
