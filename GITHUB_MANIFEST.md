# GitHub Repository Manifest — AI Revenue Agent Assets

This repository contains a complete implementation package for the AI Revenue Agent product.

## Purpose

The repo is designed to support marketing, sales, operations, and engineering teams by packaging:

- A production-ready Webflow site structure
- Sales collateral and scripts
- A Notion workspace buildout for delivery and operations
- A technical handoff for developers
- Asset metadata and integration references

## Repository Contents

- `README.md` — high-level repository overview and navigation
- `webflow/` — site map, page structure, and copy
- `sales/` — sales scripts, objection handling, discovery questions, pricing close
- `notion/` — workspace architecture, onboarding, reporting, automations, SOPs
- `technical/` — build spec, architecture, data flow, API integrations, QA, deployment
- `assets/` — JSON asset metadata for pricing and integrations

## How to Use This Repo

### For marketing or Webflow teams
1. Open `webflow/README.md`
2. Copy the page structure into Webflow pages
3. Use the content in `homepage.md`, `product-page.md`, `pricing-page.md`, `about-page.md`, and `contact-page.md`

### For sales teams
1. Open `sales/README.md`
2. Use `sales-script.md` for call structure and pitch flow
3. Use `objection-handling.md` to handle common objections
4. Use `discovery-questions.md` to qualify prospects
5. Use `pricing-close.md` to frame pricing and close deals

### For operations and delivery teams
1. Open `notion/README.md`
2. Build the Notion workspace using the pages under `notion/`
3. Follow SOPs in `notion/sops/` for onboarding, build, QA, and optimization
4. Use `notion/reporting.md` to define reporting dashboards

### For developers
1. Open `technical/README.md`
2. Use `build-spec.md` as the core implementation brief
3. Review `architecture.md`, `data-flow.md`, and `api-integrations.md`
4. Use `phase-breakdown.md` for planning the implementation timeline
5. Validate with `qa-checklist.md` before deployment
6. Use `deployment-guide.md` for go-live readiness
